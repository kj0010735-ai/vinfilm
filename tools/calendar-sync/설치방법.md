# VINFILM 캘린더 자동 동기화 설치 (처음 한 번)

1. Chrome에서 https://script.google.com 열기 (kj0010735@gmail.com 계정) → "새 프로젝트"
2. 왼쪽 위 프로젝트 이름을 "VINFILM 캘린더 동기화"로 바꾸기
3. 편집기의 `Code.gs` 내용을 전부 지우고 이 폴더의 `Code.gs` 내용을 붙여넣기
4. 왼쪽 톱니바퀴(프로젝트 설정) → "편집기에서 appsscript.json 매니페스트 파일 표시" 체크
5. 편집기로 돌아와 `appsscript.json` 내용을 전부 지우고 이 폴더의 `appsscript.json` 내용 붙여넣기 → 저장(⌘S)
6. 위쪽 함수 선택 칸에서 `setup` 고르고 "실행"
7. 권한 검토 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 "고급" → "VINFILM 캘린더 동기화(안전하지 않음)로 이동" → 허용
   (대표님이 직접 만든 스크립트라 Google 심사를 안 받아서 나오는 안내)
8. 아래 실행 로그에 "동기화 완료: 일정 N개 …"가 나오면 끝. 이후 10분마다 자동.

끄려면: 왼쪽 시계 아이콘(트리거)에서 syncNow 트리거 삭제.
